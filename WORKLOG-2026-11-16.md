# Cakes Ami website: work log, 16 Nov 2026

## Summary
The customer rejected the old site (cakesami.ca, a PHP template), so we built a **completely new static website** from scratch.
It is plain HTML, CSS and JavaScript. There is **no backend and no build step**, so it can be hosted anywhere (planned: Cloudflare Pages).

Preview locally: `cd D:\Cakes` then `python -m http.server 8765`, and open http://localhost:8765/

---
